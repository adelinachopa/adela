# Реализация мобильной версии игры "Escape to EMK"

## Обзор

Была реализована мобильная версия игры с поддержкой сенсорного управления через виртуальные джойстики. Теперь персонажи Аделина и Аня могут управляться с мобильных устройств с помощью джойстиков и кнопок. Все новые функции (система сохранения, экран проигрыша, взаимодействие блоков с кнопками) полностью поддерживаются в мобильной версии.

## Основные изменения

### 1. Система виртуальных джойстиков

Создан модуль `joystick.py`, который содержит:

- **VirtualJoystick**: Класс виртуального джойстика с поддержкой касаний и мыши
- **MobileControls**: Система управления с двумя джойстиками и кнопками действий
- **create_mobile_controls()**: Фабричная функция для создания системы управления

### 2. Адаптация графического интерфейса

В файле `setting.py` добавлены:

- Автоматическое определение мобильного устройства через переменные окружения и размер экрана
- Разные настройки для мобильных и десктопных устройств:
  - Разрешение экрана: 800×480 для мобильных, 1280×720 для десктопов
  - Размеры персонажей: уменьшены для мобильных устройств
  - Скорости движения: немного снижены для лучшего контроля на сенсорных экранах

### 3. Интеграция с основной игрой

В файле `main.py` добавлена:

- Инициализация мобильного управления при запуске на мобильном устройстве
- Обработка событий сенсорного ввода параллельно с клавиатурным
- Отрисовка элементов управления поверх игрового мира
- Автоматическое переключение между режимами управления

### 4. Управление персонажами

Система управления эмулирует нажатия клавиш клавиатуры для совместимости с существующей системой:

- **Джойстик 1 (Аделина)**: Управляет стрелками (← →)
- **Джойстик 2 (Аня)**: Управляет клавишами WASD (A D)
- **Кнопка "ПРЫЖОК"**: Активирует прыжок для обоих персонажей
- **Кнопка "ДЕЙСТВИЕ"**: Выполняет действия (поднять/бросить блок)

## Архитектура системы управления

```
MobileControls
├── VirtualJoystick (для Аделины)
├── VirtualJoystick (для Ани)
├── Кнопка "ПРЫЖОК"
└── Кнопка "ДЕЙСТВИЕ"
```

### Принцип работы:

1. Система отслеживает касания/клики мыши
2. Определяет, какой элемент управления был активирован
3. Конвертирует позиции джойстиков в направления движения (-1..1)
4. Эмулирует соответствующие нажатия клавиш клавиатуры
5. Передает эмулированные состояния в существующую систему управления игроков

## Поддержка новых функций (2026-05-21)

### Система сохранения прогресса
- Мобильная версия полностью поддерживает систему сохранения прогресса.
- Файл `save.json` создаётся и обновляется так же, как в десктопной версии.
- Сохранение происходит при завершении уровня и при проигрыше.

### Экран проигрыша
- При столкновении с врагом на мобильном устройстве отображается `LevelFailUI`.
- Кнопки "Меню" и "Начать заново" адаптированы для сенсорного ввода.
- Интерфейс масштабируется под разрешение мобильного экрана.

### Взаимодействие блоков с кнопками
- Блоки (включая блок PK) могут активировать кнопки на мобильных устройствах.
- Игрок может поднять блок с помощью кнопки "ДЕЙСТВИЕ", перенести его на кнопку и отпустить.
- Блок, оставленный на кнопке, будет удерживать её нажатой.

### UI экраны завершения уровня
- `LevelCompleteUI` и `LevelFailUI` используют полупрозрачные overlay.
- Кнопки имеют hover-эффект (на мобильных устройствах - touch feedback).
- Интерфейс адаптирован под мобильное разрешение.

## Использование

### На мобильных устройствах:

1. Запустите игру на мобильном устройстве
2. Используйте левый джойстик для управления Аделиной
3. Используйте правый джойстик для управления Аней
4. Нажимайте кнопки "ПРЫЖОК" и "ДЕЙСТВИЕ" для соответствующих действий
5. Для взаимодействия с блоками: подойдите к блоку, нажмите "ДЕЙСТВИЕ" для поднятия, перенесите блок, снова нажмите "ДЕЙСТВИЕ" для броска
6. Блоки можно использовать для нажатия кнопок - оставьте блок на кнопке, чтобы активировать её

### На десктопах (для тестирования):

1. Игра автоматически использует клавиатурное управление

## Технические детали

### Определение мобильного устройства:

```python
IS_MOBILE = False
try:
    if os.environ.get('ANDROID_ARGUMENT') or os.environ.get('IOS_SIMULATOR'):
        IS_MOBILE = True
    info = pygame.display.Info()
    if info.current_w <= 1024 or info.current_h <= 600:
        IS_MOBILE = True
except:
    pass
```

### Эмуляция клавиш:

```python
# Мобильное управление возвращает словарь состояний клавиш
mobile_keys = {
    pygame.K_LEFT: move1_x == -1,    # Джойстик 1 влево
    pygame.K_RIGHT: move1_x == 1,    # Джойстик 1 вправо
    pygame.K_UP: jump_pressed,       # Кнопка прыжка
    pygame.K_a: move2_x == -1,       # Джойстик 2 влево
    pygame.K_d: move2_x == 1,        # Джойстик 2 вправо
    pygame.K_w: jump_pressed,        # Кнопка прыжка
    pygame.K_s: action_pressed,      # Кнопка действия
}
```

### Интеграция с игровым циклом:

```python
# В основном игровом цикле (main.py)
if IS_MOBILE and mobile_controls:
    # Получаем состояния клавиш от мобильного управления
    mobile_keys = mobile_controls.handle_events(events)
    # Объединяем с клавиатурным вводом
    for key, pressed in mobile_keys.items():
        if pressed:
            keys[key] = True
```

## Обновление 2026-05-28: Адаптивный UI, мультитач и сборка APK

### 1. Адаптивный UI (Responsive)

Создан новый модуль [`responsive.py`](responsive.py) с классом `ResponsiveScaler`, который динамически масштабирует все элементы интерфейса под **любое разрешение экрана**.

**Как это работает:**
- Задаётся **базовое разрешение** (800x480 для мобильных, 1280x720 для десктопа)
- `ResponsiveScaler` вычисляет коэффициенты масштабирования по X, Y и единый
- Все размеры (кнопки, джойстики, шрифты, отступы) вычисляются относительно текущего экрана

**Изменённые файлы:**
- [`responsive.py`](responsive.py) — **НОВЫЙ**: класс `ResponsiveScaler` с методами `scale_value()`, `scale_rect()`, `scale_font_size()`, `get_font()`, `get_relative_position()` и др.
- [`setting.py`](setting.py) — добавлены `BASE_WIDTH`/`BASE_HEIGHT`, убрана жёсткая привязка размеров к `IS_MOBILE`
- [`joystick.py`](joystick.py) — все размеры джойстиков и кнопок вычисляются через `ResponsiveScaler`
- [`entities.py`](entities.py) — `LevelCompleteUI` и `LevelFailUI` используют масштабирование
- [`menu.py`](menu.py) — адаптивные размеры кнопок и шрифтов
- [`level_select.py`](level_select.py) — адаптивные размеры кнопок уровней
- [`main.py`](main.py) — интеграция `ResponsiveScaler`, передача реальных размеров экрана

### 2. Полноценная поддержка мультитач

В [`joystick.py`](joystick.py) полностью переработана система обработки касаний:

**Новый класс `MobileButton`:**
- Выделен в отдельный класс для кнопок "ПРЫЖОК" и "ДЕЙСТВИЕ"
- Каждая кнопка имеет собственный `touch_id`
- Кнопка остаётся нажатой, пока палец на ней

**Улучшенная система захвата касаний:**
- `VirtualJoystick.claim_touch(touch_id)` — захват касания джойстиком
- `VirtualJoystick.release_touch(touch_id)` — освобождение касания
- `MobileButton.claim_touch(touch_id)` / `release_touch(touch_id)` — для кнопок

**Приоритет обработки:**
1. Джойстик 1 (Аделина)
2. Джойстик 2 (Аня)
3. Кнопка "ПРЫЖОК"
4. Кнопка "ДЕЙСТВИЕ"

Теперь можно одновременно:
- Управлять Аделиной левым джойстиком
- Управлять Аней правым джойстиком
- Нажимать кнопки действий
