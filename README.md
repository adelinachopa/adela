# Escape to EMK - 2D Платформер

![Game Screenshot](image/background/level1.jpg)

## Описание
"Escape to EMK" - это 2D платформер, разработанный на PyGame. Игра поддерживает кооперативный режим для двух игроков, систему врагов с ИИ, интерактивные блоки и несколько уровней сложности.

## Особенности
- 🎮 **Кооперативный режим** - играйте вдвоем на одной клавиатуре
- 👾 **Умные враги** - патрулирующие противники с базовым ИИ
- 🧱 **Взаимодействие с блоками** - поднимайте и бросайте блоки для решения головоломок
- 🐛 **Система обработки ошибок** - автоматическое логирование ошибок в файл `game_errors.log`
- 📁 **JSON уровни** - уровни загружаются из JSON файлов с валидацией
- 🎯 **Точные коллизии** - хитбоксы 80% ширины для реалистичного взаимодействия
- 🔧 **Отладочный режим** - подробное логирование для диагностики проблем
- 🏞️ **Красивая графика** - спрайты персонажей и текстурированные платформы
- 💾 **Сохранение прогресса** - автоматическое сохранение пройденных уровней и собранных питончиков в JSON
- 🚪 **Интерактивные кнопки и двери** - кнопки открывают/закрывают двери, реагируют на игроков и блоки
- 📊 **Экраны завершения и проигрыша** - UI с кнопками "Меню", "Начать заново", "Следующий уровень"
- 🎚️ **Вертикальные движущиеся блоки** - управляются вертикальными кнопками
- 🧩 **Блок PK** - специальный блок, который также может активировать кнопки

## Установка

### Требования
- Python 3.8+
- PyGame 2.5.0+

### Шаги установки
1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd "escape to EMK"
```

2. Создайте виртуальное окружение:
```bash
python -m venv .venv
```

3. Активируйте виртуальное окружение:
- Windows:
```bash
.venv\Scripts\activate
```
- Linux/Mac:
```bash
source .venv/bin/activate
```

4. Установите зависимости:
```bash
pip install -r requirements.txt
```

5. Запустите игру:
```bash
python main.py
```

## Управление

### Игрок 1 (Аделина - синяя)
- **Влево**: Стрелка влево (←)
- **Вправо**: Стрелка вправо (→)
- **Прыжок**: Стрелка вверх (↑)
- **Взаимодействие с блоками**: Стрелка вниз (↓) - поднять/бросить блок

### Игрок 2 (Аня - красная)
- **Влево**: A
- **Вправо**: D
- **Прыжок**: W
- *Примечание: Аня не может поднимать блоки*

### Общее управление
- **ESC**: Выход из игры

## Механика игры

### Поднятие и бросание блоков
- Только Аделина может поднимать блоки (клавиша "вниз").
- Поднятый блок размещается над головой персонажа.
- Бросок осуществляется повторным нажатием клавиши "вниз" (с кулдауном 10 кадров).
- Блок летит по параболической траектории с гравитацией.
- Блоки можно толкать, если они не подняты и не брошены.

### Коллизии
- Хитбоксы игроков составляют 80% ширины спрайта для более реалистичного взаимодействия.
- Блоки являются твёрдыми объектами, с которыми можно сталкиваться.
- При падении блока на игрока блок приземляется на игрока, а не толкает его в сторону.
- Приоритет вертикальных коллизий над горизонтальными предотвращает нежелательное толкание.

### Враги
- Враги патрулируют между заданными точками.
- При столкновении с игроком игра завершается (экран проигрыша).

### Кнопки и двери
- Кнопки (Button) открывают/закрывают двери при нажатии.
- Кнопки реагируют на игроков и на блоки (включая блок PK), если блок не переносится и не брошен.
- Вертикальные кнопки (VerticalButton) управляют движением вертикальных блоков (MovingBlock).
- Двери (Door) открываются/закрываются плавно.

### Сохранение прогресса
- Игра автоматически сохраняет прогресс в файл `save.json`.
- Сохраняются пройденные уровни, количество собранных питончиков, лучший результат по собранным питончикам на уровне.
- При повторном прохождении уровня сохраняется максимальное количество собранных питончиков.
- Сохранение происходит при успешном завершении уровня (активация двери выхода) и при проигрыше.

### Экран завершения уровня
- При активации двери выхода появляется UI с кнопками "Меню", "Начать заново", "Следующий уровень".
- Отображается статистика: собрано питончиков на уровне.

### Экран проигрыша
- При столкновении с врагом появляется UI с красноватым фоном и кнопками "Меню", "Начать заново".
- Прогресс сохраняется (уровень отмечается как пройденный, если ранее был пройден).

## Разработка

### Запуск в режиме разработки
```bash
# С флагом отладки (включает дополнительное логирование)
python main.py --debug

# С выводом логов в консоль
python main.py --verbose
```

### Тестирование
```bash
# Запуск тестов
python -m pytest tests/
```

### Сборка
```bash
# Создание исполняемого файла (в разработке)
pyinstaller --onefile --windowed main.py
```

### Система обработки ошибок
Игра использует класс `GameErrorHandler` для централизованного логирования ошибок. Все ошибки, предупреждения и отладочные сообщения записываются в `game_errors.log` с метками времени и контекстом.

### JSON уровни
Уровни описываются в JSON файлах с определённой схемой. Подробности см. в `assist_yandex_history/LEVEL_JSON_SCHEMA.md`.
