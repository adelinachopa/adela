# План исправления логики MovingBlock

## Текущая проблема

В файле `levels/level_01.json` есть `moving_blocks` (строка 247) — движущийся блок с `block_id: "moving_block_1"`, который управляется вертикальной кнопкой (`vertical_buttons`, строка 261).

**Текущее некорректное поведение:**
1. Когда игрок (Аделина или Аня) стоит на движущемся блоке, и блок движется вниз — игрок принудительно перемещается вниз вместе с блоком (строка 892 в `entities.py`).
2. Когда игрок стоит на блоке, блок движется вверх, и игрок упирается головой в платформу/потолок — игрок не должен перемещаться сквозь стены, а блок должен останавливаться.

**Желаемое поведение:**
1. Если игрок стоит на `moving_block` — блок **не должен двигаться**, пока игрок на нём стоит (блок останавливается).
2. Если игрок стоит на блоке, блок движется вверх, и игрок сталкивается с платформой/стеной/потолком — игрок остаётся на месте, а блок **останавливается** (не продавливает игрока сквозь геометрию).

## Детальный анализ кода

### Файл: `entities.py`, класс `MovingBlock` (строки 807-925)

**Метод `update()` (строка 820):**
- При `self.moving = True` блок смещается на `self.move_speed` за кадр.
- После смещения вызывается `_check_collision()`.

**Метод `_check_collision()` (строка 866):**
- **Коллизия с платформой (строка 872-883):** Если блок врезался в платформу — движение останавливается, блок откатывается на шаг назад.
- **Коллизия с игроком при движении вниз (строка 889-900):**
  - Если игрок **сверху** блока (стоит на нём) — игрок принудительно сдвигается вниз (`player.rect.y += self.move_speed`). **Это нужно изменить.**
  - Если игрок **сбоку** — блок останавливается, `blocked_by_player = True`.
- **Коллизия с игроком при движении вверх (строка 901-911):**
  - Если игрок **снизу** блока (удар головой) — блок останавливается, `blocked_by_player = True`.
  - Если игрок **сбоку** — блок останавливается, `blocked_by_player = True`.

**Пробел в логике:** Нет обработки случая, когда игрок **стоит на блоке**, блок движется **вверх**, и игрок **упирается головой в платформу**. В этом случае блок продолжает движение, и игрок может пройти сквозь геометрию.

### Файл: `levels.py`, метод `Level.update()` (строка 352)

После обновления `moving_blocks` и `players` (строки 355-361), выполняется коррекция позиции игроков относительно движущихся блоков (строки 365-379):
- Если игрок внутри блока — ставится на верхнюю грань.
- Если игрок стоит на блоке — `on_ground = True`, `vy = 0`.

Это коррекция, но она не решает проблему, т.к. блок уже мог сдвинуть игрока или пройти сквозь него.

## План изменений

### Изменение 1: `entities.py` — класс `MovingBlock._check_collision()`

**Суть:** Изменить логику так, чтобы:
1. Если игрок стоит **на** блоке (сверху) — блок **не двигается**, а не толкает игрока вниз.
2. Если игрок стоит на блоке, блок едет вверх, и игрок упирается в платформу — блок останавливается.

#### Конкретные изменения в методе `_check_collision()` (строка 866):

**Случай A: Блок движется вниз (`not self.move_up`)**

Текущий код (строки 889-900):
```python
if not self.move_up:  # блок движется вниз
    # Игрок сверху блока (стоит на нём) — толкаем игрока вниз
    if player.rect.bottom <= self.rect.top + self.move_speed + 5:
        player.rect.y += self.move_speed
        player.on_ground = True
        player.vy = 0
        # Блок продолжает движение
    else:
        # Игрок врезался сбоку — останавливаем блок на месте
        self.moving = False
        self.blocked_by_player = True
        return
```

Новый код:
```python
if not self.move_up:  # блок движется вниз
    # Игрок сверху блока (стоит на нём) — останавливаем блок
    if player.rect.bottom <= self.rect.top + self.move_speed + 5:
        self.moving = False
        self.blocked_by_player = True
        # Откатываем блок на шаг назад
        self.rect.y -= self.move_speed
        self.current_offset -= self.move_speed
        return
    else:
        # Игрок врезался сбоку — останавливаем блок на месте
        self.moving = False
        self.blocked_by_player = True
        return
```

**Случай B: Блок движется вверх (`self.move_up`)**

Текущий код (строки 901-911):
```python
else:  # блок движется вверх
    # Игрок снизу блока (удар головой) — останавливаем блок на месте
    if player.rect.top >= self.rect.bottom - self.move_speed - 5:
        self.moving = False
        self.blocked_by_player = True
        return
    else:
        # Игрок врезался сбоку — останавливаем блок на месте
        self.moving = False
        self.blocked_by_player = True
        return
```

Новый код:
```python
else:  # блок движется вверх
    # Игрок сверху блока (стоит на нём)
    if player.rect.bottom <= self.rect.top + self.move_speed + 5:
        # Проверяем, может ли игрок двигаться вверх вместе с блоком
        # Если над игроком есть платформа — блок должен остановиться
        self.moving = False
        self.blocked_by_player = True
        # Откатываем блок на шаг назад
        self.rect.y += self.move_speed
        self.current_offset += self.move_speed
        return
    # Игрок снизу блока (удар головой) — останавливаем блок на месте
    elif player.rect.top >= self.rect.bottom - self.move_speed - 5:
        self.moving = False
        self.blocked_by_player = True
        return
    else:
        # Игрок врезался сбоку — останавливаем блок на месте
        self.moving = False
        self.blocked_by_player = True
        return
```

### Изменение 2: `entities.py` — класс `MovingBlock.update()`, секция возврата (строки 847-864)

**Суть:** Когда блок не двигается (`self.moving = False`) и не заблокирован игроком, он возвращается в исходную позицию. Нужно убедиться, что при возврате блок также проверяет коллизии с игроками, чтобы не задавить их.

Добавить проверку коллизий с игроками при возврате в исходную позицию.

### Изменение 3: `levels.py` — метод `Level.update()`, секция коррекции (строки 365-379)

**Суть:** Убрать принудительное выставление игрока на верхнюю грань блока, если блок заблокирован (`blocked_by_player = True`). Вместо этого просто корректировать `on_ground`, если игрок действительно стоит на блоке.

## Проверка

После внесения изменений необходимо проверить следующие сценарии:

1. **Игрок стоит на moving_block, блок движется вниз** → блок останавливается, игрок не двигается.
2. **Игрок стоит на moving_block, блок движется вверх, над игроком есть платформа** → блок останавливается, игрок не продавливается сквозь платформу.
3. **Игрок стоит на moving_block, блок движется вверх, над игроком нет платформы** → игрок поднимается вместе с блоком (как лифт).
4. **Игрок стоит на moving_block, блок возвращается в исходную позицию** → игрок не должен проваливаться сквозь блок.
5. **Игрок сбоку от moving_block** → блок останавливается (как и сейчас).
6. **Игрок снизу moving_block (удар головой)** → блок останавливается (как и сейчас).
